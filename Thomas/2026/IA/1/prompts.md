# Histórico de Prompts (Agente de IA)

1. **Geração da Spec**: "Crie uma Specification (spec.md) com os 16 pontos obrigatórios para o Sistema Escolar, como objetivo, tabelas de BD, RFs, RNFs e endpoints, sem código, apenas design."
2. **Setup do Projeto**: "Crie a estrutura de pastas Node.js, package.json com Express/MySQL/JWT e base inicial do `server.js` em src/."
3. **Modelagem**: "Gere o script SQL com as tabelas de usuarios, alunos, turmas baseadas na Spec aprovada."
